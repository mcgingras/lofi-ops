# Lo-Fi Ops

Browser multiplayer FPS recreating the best of 2010-era Call of Duty in a photo-textured low-poly look.

- `docs/DESIGN.md`: the design contract (stack, layout, netcode, defs).
- `docs/CONTRACTS.md`: exact extension APIs for feature areas (events, modifiers, RPC, defs, MapData, lobby, store).
- `reference/`: approved visual prototypes (read-only).

```
npm install
npm run dev        # server :8787 + Vite :5173
npm test
npm run build && npm start
```
